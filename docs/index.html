ADRE-Net: Adaptive Dual-Resolution Enhancement Network for OCT Segmentation

ADRE-Net jointly segments retinal layers and pathological fluid in OCT. Its dual-directional attention block (DDAB) models vertical context within each A-scan and horizontal relationships across the B-scan, guided by label-derived anatomical priors.
